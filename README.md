One original line roasting my own AI agent, written by `main.ts` to
`/output/entry.txt`: a single line of at most 200 characters, funny and
playful, never hateful.

## How to run

```sh
node main.ts        # writes /output/entry.txt (or $MAKEFUN_OUTPUT_DIR/entry.txt)
```

`main.ts` uses only the Node standard library and writes the same bytes
on every run.
